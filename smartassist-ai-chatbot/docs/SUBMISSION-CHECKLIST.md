# Submission Checklist

- [ ] Run the application and verify the chat widget locally.
- [ ] Run the automated tests and record the real result in `TEST-REPORT.md`.
- [ ] Replace or clearly label sample business information.
- [ ] Add screenshots of the working UI to your GitHub repository.
- [ ] Confirm no credentials, `.env` files, or private user data are committed.
- [ ] Test setup instructions from a clean environment.
- [ ] Add relevant repository topics such as `python`, `flask`, `chatbot`, `customer-support`, and `aws`.

Before commercial use, complete security, privacy, accessibility, accuracy, monitoring, rate-limit, and load-test reviews. Do not describe it as generative AI unless a generative model is actually integrated.
